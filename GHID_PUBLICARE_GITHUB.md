# Publicare Laborator Dentar CDL pe GitHub Pages

Site-ul este configurat pentru publicare automata prin GitHub Actions.

1. Incarca toate fisierele si directoarele din arhiva in radacina repository-ului.
2. Confirma modificarile pe ramura `main`.
3. In GitHub, deschide **Settings > Pages** si selecteaza **Source: GitHub Actions**.
4. Deschide fila **Actions** si asteapta finalizarea workflow-ului `Deploy CDL multilingual site`.
5. Verifica site-ul public, WhatsApp, apelul, meniul, limbile si formularul de email.

Nu modifica manual directorul `_site`; acesta este creat automat la publicare.
